# Booked Up 📚

A calm, editorial iOS reading companion to discover books, organise a personal library, track reading progress and collect reflections along the way.

> Work in progress — SwiftUI portfolio MVP, November 2026.

## What it does
- Discover and search a curated list of books.
- Organise books by reading status: Want to Read, Reading, Finished and DNF.
- Track reading progress and keep notes.
- Rate finished books and view personal reading statistics.

## Tech stack
Swift • SwiftUI • SwiftData • Xcode • Figma

## Design
Designed in Figma with Playfair Display + SF Pro and an editorial palette inspired by warm paper, sage green and cocoa brown.

## Running locally
1. Open `BookedUp.xcodeproj` in Xcode (created using the standard iOS App template).
2. Select an iOS simulator.
3. Press `Cmd + R`.
